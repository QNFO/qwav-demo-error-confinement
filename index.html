Error confinement map

The strong triangle inequality: any two p-adic balls are either disjoint or nested. Errors in one branch can never leak into a disjoint sibling branch — the definition of confinement.

Why the curve falls so fast

At every level, a block of p children is protected by a majority vote (the repetition-code limit of a concatenated tree code). A level with block error rate ε produces a next-level error rate approximately:

εk+1 ≈ Σj > ⌊p/2⌋ C(p,j) · εkj · (1−εk)p−j

Because εk is tiny, each level squares the suppression. At ε = 1%, p = 3, depth 7, the logical rate is astronomically small — the "zero errors at depth 7" you can now make visible yourself. The strong triangle inequality is what guarantees the recursion is valid: errors do not mix across disjoint balls.

What you're seeing

Bruhat–Tits tree: the boundary of this p-ary tree is the p-adic number line ℚp; nodes are balls, edges are inclusions. Adjusting p changes the branching of the ultrametric space; adjusting d changes concatenation depth.

Error confinement: a leaf error (red flash) contaminates its own ball, but the ball is isolated — siblings remain clean. The confinement map on the right shows this visually: pick any subtree, and its disjoint neighbors never inherit its errors.

Model transparency: this demo uses a majority-vote repetition encoding — the cleanest pedagogical analog of concatenated-tree error confinement. It is not a claim about physical hardware.†
